# Team Work App Context

- 原始记录：成员提交的原文，保存作者、发生时间、录入时间，是派生内容的证据。
- 事项：项目中的可追踪工作或问题，以稳定 ID 标识。
- 状态事件：来自一条原始记录的事项状态变更；按发生时间、录入时间排序得到当前状态。
- 员工陈述：来源明确的输入表述，标记 reported；不代表系统已独立核实。
- 系统推断：提取阶段得出的判断，标记 inferred，需用户确认，回答时仍需区分。
- 当前状态：已登记事项的最新事件投影，不代表项目所有未记录工作。
- 检索索引：全文、向量缓存等派生数据，不替代原始记录。
- 证据集合：本次查询有权访问的原始记录及补查结果；回答引用只能来自这个集合。

独立应用范围、使用方式见 README.md；具体实现与验证边界见 ACCEPTANCE.md。不改变现有工作台与 Skill 的数据语义。

- 澄清：仅当用户能确定的范围、对象或标准缺失时暂停查询并提问；不替代库内补查，也不作为技术失败的兜底。

- 范围不匹配：用户已给出明确对象，但不属于当前查询项目，不等于对象歧义。
- 非穷尽检索：当前证据只是候选集合；未检索到不构成全库无记录的证明。
- 精确引用补查：按实体词或记录中的编号扩展候选，不推断被引用记录一定同义或事实已获批准。
