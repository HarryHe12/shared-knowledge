# Local knowledge service

One [shared-knowledge Skill](team-app/skill/SKILL.md) saves records, reviews extracted items, queries evidence and resumes clarification. No web UI.

Requires Node >=22.19 and npm. Run `npm ci`, then `npm run dev`. Run `npm run test:team` for validation. See [service documentation](team-app/README.md). Legacy wiki, workbench and graph tooling have been removed; existing data is preserved.
