# 内部知识库助手：员工使用说明

助手帮助保存工作信息、找出处和了解进展。它只使用你当前有权查看的范围，不代表所有公司资料都向所有员工公开。

## 第一次使用

先在知识库账号页申请，待管理员核实并批准，加入公司并分配门店岗位，再绑定企业微信身份。个人微信使用公司已开通的企业微信插件入口。未完成这些步骤时，请联系本公司管理员，不要使用其他同事的账号。

## 保存信息

1. 发送 `范围` 查看获准范围。
2. 发送 `/范围 完整范围编号或名称` 选择保存位置。
3. 发送 `记录：一店冷柜今天修好了，今晚复查`。
4. “已收到并进入处理队列”只表示可靠接收，等最终“已保存”及记录编号后才算入库。

多个可写范围时，助手会要求先选择一个，再重发原文；此前的原文不会自动保存。记录中尽量写清具体门店、事项、发生日期、负责人、进展和阻塞；一句话也可以。工资、人事、老板信息应放入对应管理范围，不能放入本店员工共享范围。

目前支持文字和已转写语音，不支持图片、截图或文件附件直接入库。不要把“附件尚未入库”当作成功保存。普通口语可以自动辨别意图，含糊时会追问；明确使用“记录：”或“问：”更容易判断。

## 查信息

发送 `问：一店冷柜维修进展如何？`。想查全部获准范围，先发 `/范围 全部`。店员不能查其他店或本店管理范围；公司负责人可以通过公司级入口汇总本公司门店。

回答应带来源；没搜到不等于现实中没发生。重要决定请展开原始记录核对，发现矛盾请联系记录人。当前最好写清事项名称，暂不保证能理解“刚才那个”“它现在怎样”等指代。

## 录错、离职或网络失败

更正、撤回和删除通过已登录的电脑客户端操作，提供记录 ID 和当前版本，只有作者能改自己的原始记录。普通进展应追加新记录，不要覆盖之前真实发生的情况。

网络失败或结果不明确时，先查原记录/原请求，再决定重发，不要连续把同一条内容当新消息发送。调店或离职由管理员更新岗位/成员状态，权限实时生效；已发到微信的旧消息无法自动追回。
