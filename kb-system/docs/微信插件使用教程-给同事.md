# 微信插件使用教程 —— 在个人微信里直接用"知识库助手"

## 这是个什么东西？

"微信插件"是企业微信官方提供的功能。关注它之后，你的**个人微信**里就能找到"知识库助手"，直接发消息、收回答——**不用安装、也不用打开企业微信 App**。

就像在微信里多了一个同事，有事直接跟它说就行。

> 原理一句话：消息还是从微信插件走到公司后台的同一个知识库，和企业微信里发是完全一样的。

---

## 第一步：管理员开通（李任重操作，一次就好）

1. 电脑浏览器打开企业微信管理后台：**work.weixin.qq.com**，用企业微信扫码登录
2. 点顶部菜单 **「我的企业」**，在页面里找到 **「微信插件」**
3. 开启微信插件，页面上会出现一个 **「邀请关注」的二维码**
4. 检查一个开关：如果页面里有 **「成员使用微信插件时需要使用企业微信客户端」**，把它**关掉**（不关的话，同事在微信里点应用会被要求跳回企业微信）
5. 确认同事都已在助手应用的可见范围里：
   **「应用管理」→「自建」→「知识库助手」→「可见范围」**，把要用的同事或部门加进去
6. 把这个二维码发到群里，让大家用**个人微信**扫

> 前提：同事必须先被加进公司通讯录（管理后台「通讯录」里添加成员）。已经在企业微信里的同事跳过这条。

---

## 第二步：同事关注（每人 1 分钟）

1. 用**个人微信**扫管理员发的二维码，关注「微信插件」
2. 打开微信 → **「通讯录」** → 找到 **「我的企业」（你们公司的名字）** → 点进去
3. 在企业里找到 **「知识库助手」** → 点开，就是一个聊天窗口
4. **检查两个设置**（很重要，否则可能收不到回答）：
   - 进入企业页面 → 右上角 **「+」** → **「设置」** → **「接收应用消息」**：打开
   - 同一菜单里的 **「停用的应用」**：如果"知识库助手"在里面，点它重新启用

---

## 第三步：怎么用（跟在企业微信里一模一样）

在聊天窗口里直接打字就行：

| 你想干什么 | 就这样发 |
|---|---|
| 投喂工作进展、决定、想法 | 直接发大白话，不用格式 |
| 提问 | 「问：xxx」或者直接一句话结尾带"？" |
| 看使用说明 | 发「帮助」 |
| 撤回发错的内容 | 发「作废 #编号」（编号在收录回执里） |

- 投喂后几秒会收到「已收录 ✅」回执
- 提问后先收到「正在查知识库…」，几秒后答案就推过来了

---

## 常见问题

**1. 关注后在企业里找不到"知识库助手"？**
按顺序检查：① 你是不是在应用的可见范围里（找管理员确认）；② 看看「停用的应用」里有没有它；③ 确认是从「通讯录 → 我的企业」里进去的，不是搜的。

**2. 能发消息但收不到回答？**
大概率是「接收应用消息」没打开（第二步第 4 条）。还不行就把微信里这个企业的页面截图发给管理员。

**3. 点开提示"请使用企业微信客户端"？**
让管理员去「我的企业 → 微信插件」里把「成员使用微信插件时需要使用企业微信客户端」那个开关关掉。

**4. 微信插件和企业微信 App 里用，有区别吗？**
数据完全互通，发哪边都进同一个知识库。区别只是微信插件的界面简陋一点；发图片、语音这类消息，建议还是在企业微信 App 里发，微信里发文字最顺手。

**5. 群里说的话它能自动收进去吗？**
不能（企业微信的规定，机器人听不了群消息）。群里聊到重要内容，**长按那条消息 → 转发 → 选"知识库助手"**，5 秒进库。
